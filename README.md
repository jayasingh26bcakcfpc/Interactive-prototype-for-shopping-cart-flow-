# Interactive-prototype-for-shopping-cart-flow-
 Project Overview

The **Add to Cart** feature allows users to easily save selected products for purchase. Users can choose a product, select the required options, and add it to their cart with a simple tap. The cart provides a clear overview of selected items, quantities, and prices, making the shopping process simple and convenient.

The main goal is to create a **smooth, user-friendly shopping experience** with easy product selection, cart management, and quick access to checkout.
